📝 De un Vistazo: Comando Central

Todo lo que necesitas para preparar y ejecutar esta misión en minutos.

🎯 Objetivo de Aprendizaje

Los estudiantes podrán: Comprender el cuerpo como lenguaje y la relación entre cinemática y expresión. Usar el Micro:Bit junto con el robot XGO para posicionar patas, así como grabar y reproducir poses mediante el control por grados de libertad (DoF).

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Quiero aprender a crear posturas personalizadas para el XGO usando Python y guardarlas como poses. Explícame primero cómo los grados de libertad (DoF) permiten que cada pierna se coloque en una posición específica. Luego enséñame a usar xgo.set_leg_position(x,y,z) para cambiar la posición de una pierna y cómo grabar esa postura con xgo.record_pose(n) y reproducirla con xgo.set_to_pose(n). Guíame para crear 3 poses: una de equilibrio (postura firme), una de acción (lista para moverse) y una de expresión (como “saludo”). Incluye un paso de seguridad: probar cambios pequeños antes de extremos.

Usar el robot XGO para crear y guardar diferentes posiciones de sus patas.

🚨 Resolución Rápida de Problemas

  • Si los alumnos no pueden ingresar a Gnius Space: Activa XOLO SOS en xolo.gnius.club para continuar la misión sin interrumpir la clase.
  • Si el XGO no responde: Verificar que la batería esté cargada y el interruptor en ON. Revisar que el micro:bit esté bien insertado en la ranura.
  • Si el XGO pierde el equilibrio: Asegurarse de que las coordenadas (x,y,z) no sean extremas. Probar poses más cercanas al centro.
  • Si hay errores en el código: Recordar a los estudiantes que XOLO puede ayudar a depurar. Pídeles que copien el error y se lo muestren a XOLO.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear un proyecto donde el XGO use poses para comunicar emociones o estados físicos. Dame 4 emociones/estados (feliz, alerta, cansado, sorprendido) y sugiere una pose para cada uno. Después crea un “diccionario de poses” (pose 1, pose 2, pose 3…) y genera el código Python para grabarlas y reproducirlas como una rutina rápida. Luego dame el código en Python para ejecutarlo, de acuerdo a tu entrenamiento con el robot XGO y Micro:bit."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿Funciona como esperabas al reproducir la pose grabada?
  • ¿Qué pasa si intentas una pose con un centro de gravedad muy alto?
  • ¿Funciona igual la pose en el suelo que sobre una mesa?
  • ¿Cómo ayuda el diseño de señales robóticas a que entendamos qué siente el XGO?
  • ¿Qué relación hay entre la cinemática de las patas y la expresión de una emoción como el miedo?

¡Es hora de crear! Vamos a usar lo que aprendimos para darle personalidad a nuestro XGO. El flujo es sencillo: ideen con XOLO, definan el VIBE de sus emociones, obtengan su GCS, pásenlo a MakeCode y experimenten. Por ejemplo, podrían crear una rutina donde el XGO se vea sorprendido al detectar algo y luego se ponga en estado de alerta. Prueben si sus poses realmente transmiten lo que imaginan. Recuerden manejar el hardware con cuidado al encenderlo. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar su código para que las poses salgan perfectas.
